# Handwritten Alphabets Classification
This is a collaboration to complete the final project of the **Machine Learning** course at FCAI CU.

## Description
Machine learning models to classify handwritten alphabets.

Three models are used to classify the handwriting:
* Logistic Regression
* SVM (Support Vector Machine)
* Neural Networks

### Here are the main steps to build the models:
1. Loading the [handwritten_data.csv](https://www.kaggle.com/datasets/sachinpatel21/az-handwritten-alphabets-in-csv-format) dataset.
2. Data exploration, preparation and analysis.
3. Experiment #1: Train 2 SVM models with linear and non-linear kernels.
4. Experiment #2: Implement logistic regression for one-versus-all multi-class classification. (from scratch)
5. Experiment #3: Design 2 Neural Networks using `TensorFlow`.
6. Final report summarizing the following:  
  6.1 Comparing results of performance of implemented models.  
  6.2 Suggestion for best model to use.
